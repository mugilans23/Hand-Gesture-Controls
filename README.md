# AI Gesture Control — Vision Control Center

## Setup
1. Create/activate your Python 3.13 virtual environment.
2. Install:
   python -m pip install -r requirements.txt
3. Put the official MediaPipe Hand Landmarker model at:
   models/hand_landmarker.task
4. Run:
   python main.py

## Controls
Index finger = cursor
Pinch = left click
Two fingers = right click
Fist = drag
Thumb up/down = volume
OK sign = play/pause
Open palm: move hand up to increase brightness, down to decrease it
Swipe left/right = previous/next
ESC = emergency exit
